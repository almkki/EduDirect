EduDirect

AI-powered educational platform designed to assist students with
structured learning and interactive content delivery.

Live Demo: https://edudirect.onrender.com/ GitHub:
https://github.com/almkki/EduDirect

------------------------------------------------------------------------

OVERVIEW

EduDirect is a web-based educational platform that integrates
AI-assisted features to enhance learning experiences. The system
demonstrates deployment of a full-stack application with backend
services and a publicly accessible web interface.

This project is currently deployed as a working demo version. Some
advanced features are partially implemented or under development.

------------------------------------------------------------------------

FEATURES

-   Web-based educational interface
-   AI-assisted functionality (core concept integration)
-   Backend service architecture
-   Public cloud deployment (Render)
-   Modular structure for future expansion

------------------------------------------------------------------------

TECH STACK

-   Python
-   HTML / CSS / JavaScript
-   Render (deployment)

------------------------------------------------------------------------

LOCAL SETUP (DEV ONLY)

1.  Install dependencies: pip install -r requirements.txt

2.  Run server: python server.py

3.  Open: http://127.0.0.1:8000/

PROJECT STATUS
